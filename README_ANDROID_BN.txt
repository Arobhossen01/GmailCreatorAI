Gmail Creator AI — Android Studio Project

এই ZIP একটি Android Studio project, তৈরি APK নয়।

APK বানানোর ধাপ:
1. Android Studio-তে এই ZIP extract করা folder Open করুন।
2. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
3. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
4. APK পাওয়া যাবে: app/build/outputs/apk/debug/app-debug.apk

ডেমো লাইসেন্স কী: DEMO-2026-KEY1

সীমাবদ্ধতা:
- Demo key অ্যাপের HTML-এ hard-coded; এটি নিরাপদ লাইসেন্স ব্যবস্থা নয়।
- অ্যাপ Gmail account স্বয়ংক্রিয়ভাবে তৈরি করে না, OTP/CAPTCHA/phone verification bypass করে না।
- Google signup আলাদা browser-এ খোলে।
- Telegram support URL placeholder হিসেবে আছে; প্রকাশের আগে নিজের অফিসিয়াল URL বসাতে হবে।
